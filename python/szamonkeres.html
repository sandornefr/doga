Az AI pontozás a Groq AI segítségével működik (ingyenes, gyors).
A Groq API kulcsot egyszer kell beállítani a Railway environment variables között.
Kulcs igénylése: console.groq.com → API Keys → Create (ingyenes, nem kell billing)
Beállítás lépései:
1. Nyisd meg: console.groq.com → API Keys → Create API key
2. railway.app → projekt → Variables fül → adj hozzá:
   GROQ_API_KEY = a gsk_... kulcsod
3. Railway automatikusan újraindítja a szervert
4. Kattints az alábbi Tesztelés gombra — ha zöld, kész!
