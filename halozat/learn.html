Mit kell tudnod a feladatokhoz?

Nincs hosszú szöveg. Csak 3 parancs, egy séma, és másolható receptek. Elég 10 perc, utána már érteni fogod, mi történik a terminálban.

1

Gondolj rá úgy, mint egy telefonra

A Cisco routernek is van "zárolt" és "feloldott" állapota. Parancsokkal lépkedsz előre – mint szinteket egy játékban.
Zárolt
(User)
Router>
Feloldva
(Enable)
Router#
Beállítások
(Config)
(config)#
Egy port
beállítása
(config-if)#
A > karakter = zárolt. A # karakter = feloldott. Ha # van a promptban, akkor tudsz konfigurálni.
2

3 parancs, amit MINDENKÉPPEN tudnod kell

1. parancs
enable
A >-ből #-ba lép. Ezt mindig elsőnek kell beírni.
2. parancs
configure terminal
Megnyitja a beállítási módot. Ezután tudsz IP-t, jelszót, nevet beállítani.
3. parancs
no shutdown
Bekapcsolja a portot. Minden interfész alapból ki van kapcsolva – ezt ne felejtsd el!
Tipp: A Tab kiegészíti a parancsot. Nem kell mindent begépelni: conf t = configure terminal, int g0/0 = interface GigabitEthernet0/0
3

Próbáld ki! – Mini terminál

Írd be: enable, majd configure terminal, majd interface GigabitEthernet0/0, végül exit. Figyeld, hogyan változik a prompt!
Gyakorló terminál Tab = kiegészítés  ·  ↑ = előzmény
Router>
4

Parancsok – kattints a feladatra

IP-cím beállítása egy interfészen Router G0/0, G0/1
1
Belépés enable módba, majd konfigurációs módba
2
Megadjuk, melyik interfészt akarjuk beállítani
3
IP-cím + alhálózati maszk megadása
4
no shutdown – bekapcsoljuk az interfészt (kötelező!)
Router> enable
Router# configure terminal
Router(config)# interface GigabitEthernet0/1
Router(config-if)# ip address 192.168.30.65 255.255.255.240
Router(config-if)# no shutdown
Router(config-if)# exit
-- Ugyanígy a másik interfészre is (G0/0)
Switch menedzsment IP + átjáró Vlan1 + default-gateway
1
A switchnek nem G0/0-ra, hanem Vlan1-re kell az IP-t beállítani
2
Az ip default-gateway megmondja a switchnek, hova küldje a forgalmat (ez a router IP-je)
SW1(config)# interface Vlan1
SW1(config-if)# ip address 192.168.30.66 255.255.255.240
SW1(config-if)# no shutdown
SW1(config-if)# exit
SW1(config)# ip default-gateway 192.168.30.65
Biztonság + SSH beállítás hostname, jelszó, SSH kulcs, VTY
1
Névadás (hostname), jelszó titkosítva (enable secret), összes jelszó titkosítása (service password-encryption)
2
Domain név kell az SSH kulcshoz, majd crypto key generate rsa – a bitszámnál írj 2048-at
3
Helyi felhasználó létrehozása, VTY vonalak beállítása SSH-ra
Router(config)# hostname Torony
Torony(config)# enable secret Torony
Torony(config)# service password-encryption
Torony(config)# ip domain-name alapvizsga2023.hu
Torony(config)# crypto key generate rsa
-- Kérdezi a bitméretet → írj: 2048
Torony(config)# username tanuló secret Torony
Torony(config)# line vty 0 15
Torony(config-line)# transport input ssh
Torony(config-line)# login local
Torony(config-line)# exit
Konfiguráció mentése write memory – mindig a végén!
1
Ha nem mentesz, újraindítás után elvész minden beállítás!
Torony(config)# end
Torony# write memory

5

Hogyan kel életre egy hálózat?

Egy teljes folyamat – lépésről lépésre, ahogy a Packet Tracerben is csinálod. CLI parancsok és grafikus beállítások egymás után, az ellenőrzéssel együtt.
1. lépés – Router: IP-cím + biztonság (CLI) Packet Tracer – terminál ablak
!
A router GigabitEthernet interfészeire állítod be az IP-t. Minden interfész alapból ki van kapcsolva – ne felejtsd el a no shutdown-t!
Router> enable
Router# configure terminal
-- Hostname és jelszó
Router(config)# hostname KR
KR(config)# enable secret kando2022
KR(config)# service password-encryption
-- Első interfész (iroda felőli oldal)
KR(config)# interface GigabitEthernet0/0
KR(config-if)# ip address 192.168.40.1 255.255.255.224
KR(config-if)# no shutdown
KR(config-if)# exit
-- Második interfész (szerver hálózat)
KR(config)# interface GigabitEthernet0/1
KR(config-if)# ip address 192.168.40.33 255.255.255.248
KR(config-if)# no shutdown
KR(config-if)# exit
-- SSH beállítás
KR(config)# ip domain-name SSH1223.local
KR(config)# crypto key generate rsa
-- (kérdezi a bitméretet → írj: 2048)
KR(config)# username SSHladmin secret SSHladmin
KR(config)# line vty 0 15
KR(config-line)# transport input ssh
KR(config-line)# login local
KR(config-line)# exit
-- Mentés
KR(config)# end
KR# write memory
2. lépés – Switch: menedzsment IP (CLI) Packet Tracer – terminál ablak
!
A switchnek nem G0/0-ra, hanem Vlan1-re kell az IP-t beállítani. Az ip default-gateway mondja meg a switchnek, hogy a routeren keresztül érje el a többi hálózatot.
Switch> enable
Switch# configure terminal
Switch(config)# hostname k1-sw1
k1-sw1(config)# interface Vlan1
k1-sw1(config-if)# ip address 192.168.40.34 255.255.255.248
k1-sw1(config-if)# no shutdown
k1-sw1(config-if)# exit
k1-sw1(config)# ip default-gateway 192.168.40.33
k1-sw1(config)# end
k1-sw1# write memory
3. lépés – PC: IP-cím beállítása (grafikus) Packet Tracer – Desktop › IP Configuration
1
Kattints a PC-re → Desktop fül → IP Configuration ikon
2
Válaszd a Static rádiógombot (ne DHCP!)
3
Töltsd ki a mezőket az IP-tábla alapján:
IPv4 Address:192.168.40.36
Subnet Mask:255.255.255.248
Default Gateway:192.168.40.33
DNS Server:üresen hagyható
!
Fontos: A Default Gateway a router interfészének IP-je (ahol a PC csatlakozik) – nem a switch IP-je!
4. lépés – WiFi router beállítása (grafikus) Packet Tracer – Config fül
1
Kattints a WiFi routerre → Config fül
2
GLOBAL → Settings: Admin jelszó megadása
3
LAN → DHCP: Start IP és End IP megadása (pl. .100–.130)
4
Wireless → Basic Wireless Settings: SSID neve, broadcast bekapcsolása
5
Wireless → Wireless Security: Security Mode = WPA2-PSK, Passphrase = WiFi jelszó
SSID neve:ISKOLA
SSID broadcast:Enabled
Security Mode:WPA2-PSK
Passphrase:ISKOLA123
DHCP Start IP:192.168.100.100
DHCP End IP:192.168.100.130
5. lépés – Laptop / tablet WiFi-hoz csatlakoztatása Packet Tracer – PC Wireless
1
Kattints a laptopra → Desktop fül → PC Wireless
2
Megjelennek az elérhető hálózatok. Keresd az ISKOLA nevű hálózatot.
3
Kattints rá → Connect gomb → add meg a jelszót: ISKOLA123
!
Ha a DHCP jól van beállítva, a laptop automatikusan kap IP-t a 192.168.100.100–.130 tartományból.
6. lépés – Ellenőrzés: működik a hálózat? ping + show parancsok + SSH teszt
1
Ping teszt a PC-ről: Desktop → Command Prompt
C:\> ping 192.168.40.33
-- Ha "Reply from..." jelenik meg → kapcsolat OK!
-- Ha "Request timeout" → ellenőrizd az IP-ket és no shutdown
2
SSH teszt – belépés a routerre ssh-val
C:\> ssh -l SSHladmin 192.168.40.1
-- Jelszó bekéréskor: SSHladmin
-- Ha "Password:" jelenik meg → SSH működik!
3
Show parancsok a routeren – a teljes állapot megnézéséhez
KR# show ip interface brief
-- Megmutatja az összes interfészt, IP-t és állapotot
KR# show running-config
-- Az egész futó konfiguráció
Tipp: Az interfész állapota up/up legyen. Ha down/down van, elfelejtetted a no shutdown parancsot, vagy nincs kábel csatlakoztatva.
