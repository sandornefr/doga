Cisco IOS Elmélet

Parancsok, módok, konfigurációs lépések – amit a feladatok megoldásához tudnod kell

1

Cisco IOS módok

A Cisco router és switch konfigurálása módokban (privilege levels) történik. Minden módban más parancsok érhetők el. A promptból (a > vagy # karakter) tudod, hol vagy.

User EXEC
Router>
Belépéskor ide kerülsz. Csak korlátolt show parancsok. Innen nem lehet konfigurálni.
Privileged EXEC
Router#
Teljes hozzáférés show parancsokhoz, elmentés, reload. Belépés: enable
Global Config
Router(config)#
Itt állítod be: hostname, jelszó, SSH, user. Belépés: configure terminal
Interface Config
Router(config-if)#
IP-cím, aktiválás. Belépés: interface GigabitEthernet0/0
Line Config
Router(config-line)#
SSH/Telnet vonalak beállítása. Belépés: line vty 0 15
Kulcspont: Amíg a promptban > van (user mód), a configure terminal nem működik. Előbb be kell írni az enable parancsot!
2

Navigáció a módok között

Router> → enable → Router# → configure terminal → Router(config)# → interface G0/0 → Router(config-if)#
ParancsMit csinál
enableUser módból Privileged (enable) módba lép. Ha van enable password/secret, bekéri.
configure terminalEnable módból Global Config módba lép. Rövidíthető: conf t
interface <név>Config módból Interface Config módba lép a megadott interfészre.
line vty 0 15Config módból Line Config módba lép (VTY = virtuális terminál vonalak, 0–15).
exitEgy szinttel visszalép (pl. config-if → config, config → enable).
endAzonnal visszaugrik Privileged módba, bármilyen mélységből. Rövidíthető: Ctrl+Z
-- Teljes belépési folyamat elölről: Router> enable Router# configure terminal Enter configuration commands, one per line. End with CNTL/Z. Router(config)# hostname Torony Torony(config)# interface GigabitEthernet0/1 Torony(config-if)# ip address 192.168.30.65 255.255.255.240 Torony(config-if)# no shutdown Torony(config-if)# exit Torony(config)#
3

Alapkonfiguráció – biztonság

Router(config)# hostname Torony Torony(config)# enable secret Torony Torony(config)# service password-encryption
ParancsMagyarázat
hostname <név>Az eszköz neve – megjelenik a promptban és az SSH kapcsolatnál. Pl. hostname Torony
enable secret <jelszó>Jelszó az enable módhoz – titkosítva tárolódik (MD5). Biztonságosabb, mint az enable password.
service password-encryptionAz összes többi jelszót is titkosítja a konfigurációban (pl. VTY jelszók, user jelszók).
enable secret vs enable password: Mindig az enable secret-et használd! Az enable password gyengébb titkosítással tárol.
4

IP-cím beállítás – router interfész

Torony(config)# interface GigabitEthernet0/1 Torony(config-if)# ip address 192.168.30.65 255.255.255.240 Torony(config-if)# no shutdown %LINK-5-CHANGED: Interface GigabitEthernet0/1, changed state to up Torony(config-if)# exit
ParancsMagyarázat
interface G0/1Belép a GigabitEthernet0/1 interfész konfigurációjába. Sima switch esetén: interface Vlan1
ip address <ip> <maszk>Beállítja az IP-t és az alhálózati maszkot. A maszk decimális formátumban kell (pl. 255.255.255.240 = /28)
no shutdownAktiválja az interfészt – alapból ki van kapcsolva! Ez kötelező lépés, különben az interfész nem fog működni.
Switch esetén (VLAN IP): A switchnek is beállíthatunk IP-t menedzsmenthez, de azt a Vlan1 interfészre kell tenni. Ezen felül szükséges az ip default-gateway parancs is, hogy a switch tudja, merre küldje a saját alhálózatán kívüli forgalmat.
-- Switch VLAN1 IP + default gateway: SW1(config)# interface Vlan1 SW1(config-if)# ip address 192.168.30.66 255.255.255.240 SW1(config-if)# no shutdown SW1(config-if)# exit SW1(config)# ip default-gateway 192.168.30.65
5

SSH konfiguráció

Az SSH (Secure Shell) titkosított, biztonságos távoli bejelentkezést biztosít. A Telnet-tel ellentétben az SSH titkosítja a kommunikációt. Az SSH beállításhoz 4 lépés kell:

-- 1. Domain név (az RSA kulcs neve ebből áll össze) Torony(config)# ip domain-name alapvizsga2023.hu -- 2. RSA kulcspár generálása (titkosításhoz kell) Torony(config)# crypto key generate rsa How many bits in the modulus [512]: 2048 -- 3. Helyi felhasználó létrehozása Torony(config)# username tanuló secret Torony -- 4. VTY vonalak konfigurálása (0-15 = 16 párhuzamos bejelentkezési lehetőség) Torony(config)# line vty 0 15 Torony(config-line)# transport input ssh Torony(config-line)# login local Torony(config-line)# exit
ParancsMagyarázat
ip domain-name <név>Domain név – kötelező az RSA kulcs generáláshoz. A kulcs neve: hostname.domain
crypto key generate rsaRSA kulcspárt generál. A bit-méretnél 2048-at adj meg (erősebb = biztonságosabb).
username <felh> secret <jelszó>Helyi felhasználó létrehozása SSH bejelentkezéshez.
line vty 0 15A VTY vonalak konfigurációs módja. 0–15 = max 16 párhuzamos kapcsolat.
transport input sshCsak SSH kapcsolatot enged be (Telnetet nem, az titkosítatlan!)
login localA helyi felhasználói adatbázist használja azonosításhoz (a fent létrehozott username/secret).
6

Konfiguráció mentése

-- Visszatérés enable módba: Torony(config)# end -- Mentés (két egyenértékű lehetőség): Torony# write memory -- VAGY Torony# copy running-config startup-config Destination filename [startup-config]? Enter
Miért kell menteni? A Cisco router a konfigurációt alapból csak a running-config-ban (RAM) tárolja. Ha az eszközt újraindítják, a RAM törlődik, és a startup-config (NVRAM) töltődik be. A write memory átmásolja a running-config-ot a startup-config-ba, így újraindítás után is megmarad.
7

Otthoni router (Home Router / GUEST)

Az otthoni router (pl. GUEST, SULI-WIFI) nem Cisco IOS-sal, hanem grafikus felülettel (GUI) konfigurálható – rá kell kattintani a topológiában.

BeállításMit jelent
Router jelszóA router felügyeleti jelszava (admin login).
DHCP kezdő/záró IPA kiosztható IP-tartomány. Pl. 192.168.100.10 – 192.168.100.20 közötti 11 cím kiosztható automatikusan.
SSIDA WiFi hálózat neve (amit a telefonon/laptopon látunk). Pl. GUEST-WIFI
SSID BroadcastHa ki van kapcsolva, a hálózat neve nem látszik – rejtett WiFi. A szimulátorban explicit csatlakoztatni kell.
Security: WPA2-PSKJelszóval védett WiFi. A PSK = PreShared Key = a WiFi jelszó.
WiFi kulcs (Passphrase)A WiFi jelszó, amellyel a kliensek csatlakoznak.
